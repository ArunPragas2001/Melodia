# Melodia study guide

Melodia groups twelve instruments into Strings, Wind, Percussion, and Keyboard. Start on Home, choose a family in Explore, or search for an instrument by name.

## Learning from an instrument profile

Each profile has four useful parts:

1. Read the description, origin, and main components.
2. Check the setup notes before handling the instrument.
3. Work through the numbered playing steps slowly.
4. Use the practice pattern, demonstration script, goal, and beginner tip together.

The patterns use plain text so they remain readable offline and can scroll horizontally on a narrow phone. The guide is an introduction; safe posture, tuning, embouchure, and technique should be checked with a teacher where possible.

## Using favourites

Tap the heart on a card or the button on a profile. Favourites belong to the signed-in local account, so two people using the same device can keep separate collections.

## Taking the quiz

The quiz contains eight questions. Select one answer to see the correct option and a short explanation. The completed score is saved automatically and appears on Profile. Retake the quiz to improve the personal best.

## Accounts and offline data

Registration and login work locally on the device. Passwords are stored as salted SHA-256 hashes rather than plain text. Accounts, favourites, and the latest fifty quiz scores do not leave the device.

There is no password recovery or cross-device synchronisation. Clearing browser/app storage or uninstalling the app removes all local accounts and progress.
